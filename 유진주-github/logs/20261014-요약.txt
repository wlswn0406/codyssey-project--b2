**[기사 제목 번역]**
피지컬 인텔리전스, 로봇 파운데이션 모델을 위한 Pi API 베타 공개

**[영문 3줄 요약 (Original)]**
- Physical Intelligence (PI) has launched the beta of its Pi API, designed to facilitate the creation of robotic foundation models (RFMs).
- RFMs are large, general-purpose AI models for robots, enabling them to learn diverse skills from vast datasets and generalize across tasks and environments.
- This initiative aims to overcome the limitations of traditional, rigid robot programming, paving the way for adaptable and autonomous robots.

**[국문 3줄 요약 (Translated)]**
- 피지컬 인텔리전스(PI)가 로봇 파운데이션 모델(RFM) 개발을 지원하는 Pi API 베타 버전을 공개했습니다.
- RFM은 방대한 데이터 학습을 통해 다양한 기술을 습득하고 새로운 환경에 일반화할 수 있는 범용 로봇 AI 모델입니다.
- 이는 기존 로봇 프로그래밍의 한계를 넘어, 적응력 있고 자율적인 로봇의 시대를 열고자 하는 목표를 가지고 있습니다.

**[기사 제목 번역]**
AI 에이전트 스택에 의사결정 전문 레이어가 뜬다

**[영문 3줄 요약 (Original)]**
- A dedicated decision-making layer is emerging as crucial for advancing AI agent stacks beyond basic large language model (LLM) capabilities.
- This new architectural layer addresses limitations in current agents, such as poor planning and error correction, by enabling complex task breakdown and multi-step reasoning.
- It acts as a cognitive architecture or orchestration engine, integrating memory and tool use to make AI agents more robust, autonomous, and reliable.

**[국문 3줄 요약 (Translated)]**
- AI 에이전트 스택이 기본 LLM을 넘어 발전하기 위해 전용 의사결정 레이어의 등장이 핵심적인 요소로 부상하고 있습니다.
- 이 새로운 아키텍처 레이어는 복잡한 작업 분해 및 다단계 추론을 가능하게 하여 현재 에이전트의 부족한 계획 및 오류 수정 능력을 보완합니다.
- 인지 아키텍처 또는 오케스트레이션 엔진 역할을 하며, 메모리와 도구 사용을 통합하여 AI 에이전트를 더욱 견고하고 자율적으로 만듭니다.
